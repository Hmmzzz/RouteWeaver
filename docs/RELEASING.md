# 发布指南

1. 更新版本号、构建号及版本说明，写清行为变化、适用范围和验证结果。
2. 按 [贡献指南](../CONTRIBUTING.md) 完成测试与检查，确认目标提交的 CI 通过。
3. 检查源码、Git 历史、截图和最终 ZIP 是否含敏感内容。`script/check_publication.py` 只覆盖当前 Git 可见文件；发布附件与新增截图需单独审阅。
4. 运行 `./script/build_and_run.sh --build-only`，核验 App 版本、架构、严格签名及 ZIP 内容。
5. 核验包内许可证、第三方说明和 Apple ABI 组件对应源码与构建源一致。保留对应版本的源码和发布归档，满足 [代码来源](PROVENANCE.md) 中的分发要求。
6. 创建对应源码标签并上传安装包，在版本说明中提供 SHA-256；回下载附件确认哈希一致。
7. 以未登录状态检查源码、文档、Release 和下载链接，并确认 [安全报告流程](../SECURITY.md) 与实际可用渠道一致。
