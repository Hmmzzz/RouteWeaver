# 安全与隐私

发现疑似安全漏洞，请先阅读 [漏洞报告与安全维护](../SECURITY.md)，不要把漏洞细节提交到公开 Issue。

RouteWeaver 会修改本机 IPv4 路由和临时 DNS 配置，需要管理员授权安装 root 后台服务。它不是防泄漏 VPN、防火墙或匿名工具；本地构建没有 Developer ID 公证，也未经过独立安全审计。

## 权限和清理

- GUI 以普通用户运行；后台服务校验用户及安装时授权的应用签名身份，只接收受限的状态、应用和停止请求。
- 修改前记录路由意图，修改后核验；停止时撤回本应用的 DNS 与路由。已有路由冲突不会被覆盖。
- 关闭窗口继续运行；正常退出等待清理完成。强制退出由后台监测后尝试清理，失败会保留恢复记录。
- 其他 root 程序可同时修改路由，因此不能保证没有并发竞争；网络变化到检测和清理之间也存在时间窗口。

## DNS 与速率

名单命中的国内域名会尝试通过 `https://223.5.5.5/dns-query` 解析，只有返回的 IPv4 地址符合已核验直连计划才使用；其他请求或不合格结果回退到 Tailscale DNS。上游服务可看到查询域名和连接来源。本应用不记录查询名、不持久化 DNS 缓存。

国内解析默认最多等待 1.25 秒，为原 DNS 回退保留预算；单次请求整体预算为 4.5 秒。连续两次国内上游故障后，5 秒内直接使用原 DNS，随后只允许一个共享查询探测恢复。合法的空答复、非直连结果和本地取消不会被当作上游故障。

代理最多处理 64 个在途请求，其中尝试国内优化的请求最多 48 个，等待国内上游的订阅最多 32 个；每个客户端连接最多 8 个请求，其中优化请求最多 6 个。优化请求回退后仍占用原来的额度，为仅使用原 DNS 的查询保留容量。超过容量会返回失败；这些限制不保证在原 DNS 自身不可用或全部容量耗尽时仍能解析。连接关闭或请求超时会取消不再需要的上游任务；共享查询在最后一个订阅取消后才撤销。

直连速率来自已核验 IPv4 路由计数；Tailscale 速率包含整个已识别接口的流量，不限于 exit node。计数不可确认时显示“—”。部分计数使用 XNU 私有接口，系统更新可能影响兼容性。

## 本地资料与问题反馈

用户配置位于 `~/Library/Application Support/RouteWeaver`；root 策略和恢复记录位于 `/private/var/db/com.routeweaver.*`。不要手动删除恢复记录来隐藏未清理的路由。

项目内的诊断输出和历史资料放在 Git 忽略的 `work/`。反馈问题前请移除日志或截图中的设备名、Tailnet 域名、真实网络信息、用户路径和凭据；公开问题区不要附带未脱敏的诊断包。发布前运行 `python3 script/check_publication.py` 检查待公开文件。
